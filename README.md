Initial configuration, topology, and mdp files are provided so that simulations can be independently run.

For the sake of file size, published trajectories have been truncated to include only protein atoms with one frame every nanosecond. Full trajectories are available upon request. Published trajectories have been treated with the "mol" periodic boundary condition, and then fit to the initial frame for ease of viewing. The view_trajectory.pdb files can be opened in ChimeraX followed by one of the trajectory files to watch the trajectory.

Code used to analyze the simulations and produce plots are provided as a Jupyter notebook. For Gromacs analysis tools, shell scripts with example commands are provided, however note that these are strictly examples and will not run out-of-the-box.
